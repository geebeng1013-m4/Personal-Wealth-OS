# WealthUp

Personal Wealth OS: a private, offline-first tool for tracking income, spending,
cash flow, savings, investments, and financial goals. Single user; the data stays
with the user (JSON import/export, version snapshots). Runs at
[wealthup.cc](https://wealthup.cc).

**Current stage:** getting the core to a correct, usable V1. Larger new features
wait until V1 is done.
