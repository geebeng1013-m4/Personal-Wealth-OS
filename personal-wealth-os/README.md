# WealthUp

Personal Wealth OS — not just tracking where your money is, but helping you
decide what to do with it. Dashboard/Ledger/Portfolio show the current picture;
Advisor/Rules turn your own configured rules into a ranked recommendation with
its reasoning attached (fact → rule → impact → action); Review closes the loop
by confirming whether you actually followed through. Private, offline-first,
single user — data stays with you (JSON import/export, version snapshots). Runs
at [wealthup.cc](https://wealthup.cc).

**Current stage:** getting the core to a correct, usable V1. Larger new features
wait until V1 is done.
